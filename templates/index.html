First-Time Setup

This tool uses the Eleven Labs API to generate voice-over audio. You'll need a free or paid account and an API key to get started.

  1. Go to elevenlabs.io and sign in or create an account
  2. Navigate to Profile → API Keys
  3. Create a new key — enable Text to Speech, Voice Generation, and Voices (Read)
  4. Copy the key and paste it below
